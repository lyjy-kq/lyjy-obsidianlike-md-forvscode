# FlowMD 代码块与标题样式继续优化 Spec

## 背景

上一轮已将 fenced code block 的渲染收敛为语言按钮、圆角边框和缩进导引线。
本轮继续细化代码块与标题的视觉反馈，使代码块更易查阅，同时避免标题层级过度放大。

## 目标

1. 代码块缩进导引线更细，呈现为单像素级别的细线。
2. 代码块某一行存在多级缩进时，前面的缩进层级也要同时显示。
3. 代码块的 0 级缩进也要显示导引线。
4. 代码块背景色统一调整为 `#1e1f20`。
5. 代码块未显式指定语言时，复制按钮默认显示 `go`。
6. 标题字号收敛，只有一级标题保留明显放大效果，其他标题不再增大字号。
7. 代码块渲染态的字体大小、字体与行高应尽量继承编辑器基准，避免预览与编辑模式之间产生明显跳动。
8. 代码块上下边框的视觉位置应贴近 opening / closing fence 行的中线位置。

## 范围

包含以下文件的调整：

- `src/webview/codemirror/extensions/livePreview/plugin.ts`
- `src/webview/codemirror/extensions/livePreview/styles.ts`
- `src/webview/codemirror/extensions/livePreview/helpers.ts`
- `src/webview/codemirror/extensions/livePreview/widgets.ts`

不包含以下内容：

- Mermaid、表格、脚注、数学公式、图片等其他 live preview 组件的渲染逻辑
- Markdown 语法解析逻辑本身
- 导出 HTML 的样式系统

## 实施方案

1. 代码块渲染逻辑保持“原文展示 + 语言按钮 + 复制动作”，仅调整语言默认值与缩进导引线规则。
2. 缩进导引线改为更细的单像素线，并按当前行缩进深度叠加显示前置层级。
3. 代码块背景色改为统一的深色底 `#1e1f20`，边框继续保持圆角外观。
4. 复制按钮若代码块未显式声明语言，则展示 `go`。
5. 标题样式仅保留 `h1` 的轻微放大，`h2` 到 `h6` 维持正文同级字号。
6. 代码块不再额外改写字号或行高，尽量保持与编辑器一致。
7. 代码块顶部和底部的边框视觉上落在 fence 行中部。

## 验收标准

1. 代码块中任意缩进行都能看到从 0 级开始的缩进导引线。
2. 缩进线视觉上是一条细线，不再显得粗重。
3. 未声明语言的代码块按钮显示 `go`。
4. 代码块背景色为 `#1e1f20`，圆角边框仍然可见。
5. 只有一级标题有放大效果，二级到六级标题不再放大。
6. `npm run build` 可正常通过。
