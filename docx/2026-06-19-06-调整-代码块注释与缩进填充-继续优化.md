# FlowMD 代码块注释与缩进填充继续优化 Spec

## 背景

当前代码块已经完成语言按钮、圆角边框和基础缩进导引线。
这次继续把视觉细节收敛到更接近编辑器本身的表现，并把缩进视觉从“线”改成“浅色块填充”。

## 目标

1. 代码块内的注释显示为灰白色，不再斜体。
2. 缩进导引线改为浅色色块，填充 tab 区域，而不是描绘起点线。
3. 代码块边界不再在 fence 行中间绘制横线标记。
4. 代码块未显式语言时仍默认显示 `go`。
5. 代码块的字体、字号、行高继续尽量继承编辑器基准。

## 范围

包含以下文件的调整：

- `src/webview/codemirror/extensions/livePreview/decorations.ts`
- `src/webview/codemirror/extensions/livePreview/helpers.ts`
- `src/webview/codemirror/extensions/livePreview/plugin.ts`
- `src/webview/codemirror/extensions/livePreview/styles.ts`
- `src/webview/codemirror/extensions/livePreview/widgets.ts`

不包含以下内容：

- Mermaid、表格、脚注、数学公式、图片等其他 live preview 组件的渲染逻辑
- Markdown 语法解析逻辑本身
- 导出 HTML 的样式系统

## 实施方案

1. 将 fenced code block 的缩进指示改为背景填充块，按层级累积显示。
2. 代码块第一行和最后一行使用边界样式表达区块开始与结束，不再绘制 fence 中线。
3. 代码块语法高亮中的 comment 类统一改为灰白色、非斜体。
4. 代码块字体与行高继续继承编辑器主题和字体缩放设置，避免预览与编辑态跳动。

## 验收标准

1. 代码块注释看起来是灰白色，且不是斜体。
2. 缩进区域看到的是浅色填充块，而不是一条条起点线。
3. 代码块边界不再出现 fence 行中部横线。
4. 未声明语言的代码块按钮显示 `go`。
5. `npm run build` 可正常通过。
