# 2026-06-19 29 删除 搜索功能 改用VSCode原生搜索
## 背景

当前 FlowMD 在 Webview 内部自己实现了一套 `Ctrl+F` / `Ctrl+H` 搜索与替换逻辑，包括：

1. CodeMirror 6 内部搜索面板。
2. 编辑器内的搜索匹配计数。
3. 扩展侧转发 `find` / `replace` 命令到 Webview。
4. `package.json` 中对 `ctrl+f`、`ctrl+h`、`cmd+f`、`cmd+alt+f` 的插件级绑定。

这会和 VS Code 自带的文件搜索 / 替换体验冲突，也会让用户误以为 FlowMD 需要维护一套独立搜索系统。

## 目标

1. 删除 FlowMD 自己的搜索功能。
2. 删除插件对 `Ctrl+F` / `Ctrl+H` 的接管。
3. 让 Markdown 文件搜索与替换完全回到 VS Code 原生能力。
4. 清理搜索相关样式、消息与命令入口，避免残留死代码。

## 范围

### 需要修改
- `src/webview/codemirror/editor.ts`
- `src/webview/main.ts`
- `src/extension/index.ts`
- `src/extension/editorProvider.ts`
- `src/shared/messageTypes.ts`
- `src/webview/codemirror/extensions/theme.ts`
- `package.json`

### 可选清理
- `src/webview/codemirror/extensions/searchMatchCount.ts`

## 实现方案

1. 从 CodeMirror 编辑器中移除搜索面板相关扩展与快捷键拦截：
   - 删除 `@codemirror/search` 相关导入。
   - 删除搜索面板挂载逻辑。
   - 删除 `Mod-f` / `Mod-h` 的过滤逻辑。
   - 删除 `find` / `replace` 的本地执行分支。
   - 删除搜索面板 Escape 兜底处理。

2. 扩展侧不再注册搜索命令：
   - 删除 `flowMd.find`。
   - 删除 `flowMd.replace`。
   - 删除对应的 `executeWebviewCommand` 转发。

3. 配置侧不再声明插件级搜索快捷键：
   - 删除 `ctrl+f`、`ctrl+h`、`cmd+f`、`cmd+alt+f` 的贡献项。
   - 删除对应 command 的 `contributes.commands` 声明。

4. 消息协议里清理 `executeCommand`：
   - 删除扩展与 Webview 间的 `executeCommand` 消息类型。
   - 删除 Webview 侧 `executeCommand` 消息分发。

5. 清理样式：
   - 删除 `cm-search`、`cm-searchMatch`、`cm-search-match-count` 相关主题样式。

## 验收标准

1. 在 FlowMD 编辑器中按 `Ctrl+F` / `Ctrl+H` 时，不再弹出插件自带搜索面板。
2. `Ctrl+F` / `Ctrl+H` 回到 VS Code 原生搜索 / 替换行为。
3. 扩展命令列表里不再存在 FlowMD 的 find/replace 命令。
4. Webview 中不再存在 `.cm-search` 相关 DOM 或样式入口。
5. 项目构建通过，不出现未使用的搜索入口调用链。

## 测试建议

1. 打开 `.md` 文件，确认 `Ctrl+F` 打开 VS Code 原生搜索。
2. 确认 `Ctrl+H` 打开 VS Code 原生替换。
3. 确认 FlowMD 的编辑器标题栏、右键菜单等现有功能不受影响。
4. 执行一次打包构建，确保删改后没有编译错误。
