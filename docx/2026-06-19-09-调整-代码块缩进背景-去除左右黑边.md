# FlowMD 代码块缩进背景去除左右黑边 Spec

## 背景

当前 fenced code block 的缩进填充已经改为浅色块效果，但在缩进区域的最左边和最右边仍会露出一小条偏黑的底色。
这会让代码块看起来像没有完整铺满背景，影响与编辑器主题的一致性。

## 目标

1. 代码块缩进填充区域的左右边缘不再露出黑边。
2. 缩进块整体仍保持与代码块背景一致的底色 `#1e1f20`。
3. 不改变代码块现有的圆角边框、语言按钮和复制逻辑。

## 范围

包含以下文件的调整：

- `src/webview/codemirror/extensions/livePreview/helpers.ts`

不包含以下内容：

- 代码块渲染结构调整
- 代码块按钮文案调整
- 代码块字体、字号、行高调整
- 其他 Markdown 元素样式修改

## 实施方案

1. 调整代码块缩进背景的裁切与原点策略，让背景颜色覆盖 padding 区域。
2. 保持缩进色块的分层配色与现有节奏不变。
3. 保持代码块底色仍为 `#1e1f20`，确保视觉连续性。

## 验收标准

1. 缩进区域最左边不再出现黑边。
2. 缩进区域最右边不再出现黑边。
3. 代码块整体背景仍然与 `#1e1f20` 保持一致。
