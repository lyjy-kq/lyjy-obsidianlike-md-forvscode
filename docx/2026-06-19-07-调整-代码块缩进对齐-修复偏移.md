# FlowMD 代码块缩进对齐修复 Spec

## 背景

当前代码块的缩进高亮已经从线条改为浅色块填充，但存在向右多延伸一段 tab 区域的问题。
同时，代码块边界需要保持为外框开始与结束，不再出现 fence 行中部的视觉标记。

## 目标

1. 代码块缩进填充严格对齐实际 tab 区域，不得超出该行当前缩进起点。
2. 代码块缩进层数只覆盖真实存在的 tab 区域，不额外多绘制一层。
3. 代码块边界保持外框样式，不出现 fence 行中部横线标记。

## 范围

包含以下文件的调整：

- `src/webview/codemirror/extensions/livePreview/helpers.ts`
- `src/webview/codemirror/extensions/livePreview/plugin.ts`
- `src/webview/codemirror/extensions/livePreview/styles.ts`

不包含以下内容：

- 注释颜色、标题字号、默认语言等已有行为的再修改
- Mermaid、表格、脚注、数学公式、图片等其他 live preview 组件的渲染逻辑

## 实施方案

1. 修正缩进填充层数计算，使每个 tab 区域只对应一个色块。
2. 保持代码块线条边界为外框，不再叠加中线式视觉标记。
3. 维持代码块渲染态字体和行高继承编辑器基准。

## 验收标准

1. 缩进色块只覆盖当前行真实缩进区域，不再越过代码起点。
2. 缩进层级与实际 tab 数一致，不多一层。
3. 代码块边界看起来是完整外框，没有 fence 行中部横线。
4. `npm run build` 可正常通过。
