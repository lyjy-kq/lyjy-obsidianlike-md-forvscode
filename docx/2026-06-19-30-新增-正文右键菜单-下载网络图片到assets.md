# 2026-06-19 30 新增 正文右键菜单 下载网络图片到assets
## 背景

当前 FlowMD 已经支持图片插入、拖拽、粘贴以及通过扩展侧保存本地图片，但正文里如果直接写入了网络图片地址，仍然需要用户手动下载、放入 `./assets`，再逐个改链接。

用户希望在 Markdown 正文的鼠标右键菜单里新增一个动作，自动完成：

1. 识别当前文中的网络图片。
2. 将图片下载到文档同级的 `./assets` 目录。
3. 将正文中的图片链接同步改写为本地相对路径。

## 目标

1. 在正文右键菜单中新增“下载网络图片到本地”功能。
2. 将文中的网络图片批量下载到 `./assets`。
3. 自动把链接从网络地址改写为本地相对路径。
4. 尽量复用现有图片保存与正文更新链路，避免重复造轮子。

## 范围

### 需要修改
- `src/webview/editorContextMenu.ts`
- `src/webview/main.ts`
- `src/webview/messageHandler.ts`
- `src/extension/index.ts`
- `src/extension/editorProvider.ts`
- `src/extension/imageSaveHandler.ts` 或新增独立下载处理模块
- `src/shared/types.ts`
- `package.json`

### 可能新增
- 网络图片解析与下载辅助函数
- 图片链接重写辅助函数

## 实现方案

1. 在正文右键菜单中新增一个动作，例如 `downloadRemoteImages`。
2. 通过 Webview -> Extension 消息把当前正文内容发送给扩展侧处理。
3. 扩展侧解析 Markdown 正文中的网络图片链接，识别常见图片语法：
   - `![](https://example.com/a.png)`
   - `![[https://example.com/a.png]]`
   - 带空格、带中文文件名、带 query string 的图片地址
4. 将网络图片下载到文档同级 `assets` 目录。
5. 下载完成后，生成新的本地相对路径，并把正文内容整体替换后回写到 Webview / 文档。
6. 如果同一篇文档中存在多处相同网络图片引用，应尽量复用已下载文件，避免重复下载。

## 约束

1. 只处理正文右键菜单，不影响大纲、标题栏、资源管理器等其它入口。
2. 不影响现有的本地图片插入、拖拽、粘贴逻辑。
3. 网络请求失败时要给出明确错误提示，不要静默失败。
4. 写回正文时要保持尽量少的文本改动，只替换图片链接部分。

## 验收标准

1. 在 Markdown 正文右键菜单中能看到“下载网络图片到本地”功能。
2. 执行后，网络图片会被保存到文档同级 `assets` 目录。
3. 正文中的网络图片链接会自动变成本地相对路径。
4. 现有图片插入、导出 HTML、大纲等功能不受影响。
5. 构建通过。

## 测试建议

1. 准备一篇包含 `https://...png/jpg/webp/gif` 的 Markdown 文档。
2. 右键正文执行下载动作。
3. 检查 `assets` 目录是否生成文件。
4. 检查正文中的链接是否已替换成本地路径。
5. 在同时存在普通链接和图片链接的情况下，确认只改图片链接。
