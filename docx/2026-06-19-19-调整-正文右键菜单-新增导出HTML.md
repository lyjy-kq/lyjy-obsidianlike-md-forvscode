# 调整正文右键菜单新增导出HTML Spec

## 背景

FlowMD 的 Markdown 正文目前已经有一套基于 Webview 的自定义右键菜单，用于放置正文相关操作。为了减少编辑器顶部按钮和标题栏入口的干扰，需要把 `Export as HTML` 也收拢到正文右键菜单中，保持操作入口集中。

## 目标

1. 在 Markdown 正文的鼠标右键菜单中新增 `Export as HTML`。
2. 保持现有导出逻辑不变，仅调整入口位置。
3. 移除编辑器标题栏中的 `Export as HTML` 入口，避免重复入口。
4. 不影响正文编辑、图片插入、模式切换和其它已有右键行为。

## 范围

本次仅调整以下文件：

- `src/webview/editorContextMenu.ts`
- `src/webview/messageHandler.ts`
- `src/webview/main.ts`
- `src/extension/editorProvider.ts`
- `package.json`
- `src/shared/types.ts`

## 设计约束

1. 导出动作必须复用现有 `exportMarkdownAsHtml` 逻辑，不得重新实现 HTML 导出流程。
2. 右键菜单仅在 Markdown 正文区域生效，不应扩展到大纲、标题栏或其它 Webview UI。
3. 菜单样式沿用现有 VS Code 风格，不额外引入新的视觉系统。
4. 编辑器标题栏不再显示 `Export as HTML`。

## 验收标准

1. 在 Markdown 正文中右键可以看到 `Export as HTML`。
2. 点击该菜单项后，导出结果与原命令一致。
3. 编辑器标题栏不再出现 `Export as HTML`。
4. 其它正文右键功能保持正常。
