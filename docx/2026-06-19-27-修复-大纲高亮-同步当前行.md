# 2026-06-19 27 修复 大纲高亮 同步当前行

## 背景

当前右侧大纲面板能够根据行号高亮对应标题，但编辑器在切换光标、上下移动、点击定位后，没有把当前所在行持续同步给大纲面板。

结果是：大纲默认会停留在第一条标题的高亮状态，看起来像“第一条一直被选中”，而不是跟随正文当前光标位置显示对应标题的自身配色。

## 目标

1. 让大纲高亮跟随编辑器当前光标所在行同步更新。
2. 保持现有的大纲渲染结构、折叠逻辑、跳转逻辑不变。
3. 在内容更新和光标移动两种情况下，都能正确刷新大纲激活项。
4. 不改动大纲标题配色规则，只修复“选中态长期停留在第一条”的状态同步问题。

## 范围

### 需要修改

- `src/webview/codemirror/editor.ts`
- `src/webview/main.ts`

### 不需要修改

- `src/webview/outlinePanel.ts` 的标题解析和渲染结构
- `src/extension/webviewContent.ts` 的大纲样式配色
- Markdown 正文渲染逻辑

## 实现方案

1. 在编辑器封装层暴露“当前选中行变化”的通知能力。
2. 在 `main.ts` 中监听编辑器光标/选区变化，并把当前行号传给大纲面板。
3. 在初始化和外部内容刷新后，同步一次当前行，避免初始状态落在第一条标题上。
4. 保持原有 `setContent(content)` 行为不变，仅补充大纲激活行的同步。

## 验收标准

1. 打开 Markdown 文件后，大纲高亮会落在编辑器当前光标所在标题，而不是永远落在第一条。
2. 按上下方向键移动光标后，大纲高亮会即时跟随变化。
3. 外部内容刷新后，大纲高亮仍能正确回到当前光标所在行。
4. 大纲的颜色样式保持不变，没有新增视觉回归。
