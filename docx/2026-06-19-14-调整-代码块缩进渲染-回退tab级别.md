# FlowMD 代码块缩进渲染回退 tab 级别 Spec

## 背景

当前代码块缩进已经尝试过按归一化列切片渲染，但视觉对齐与阅读体验都不稳定。
需要回退到更稳定的 tab 级别渲染方式。

## 目标

1. 代码块缩进恢复为按 tab 级别渲染。
2. 不再按归一化列切片拆分多个不同宽度的色块。
3. 保持代码块背景色、边框和按钮逻辑不变。

## 范围

包含以下文件的调整：

- `src/webview/codemirror/extensions/livePreview/helpers.ts`
- `src/webview/codemirror/extensions/livePreview/plugin.ts`

不包含以下内容：

- 代码块结构调整
- 代码块字体、行高与边框
- 其他 Markdown 元素

## 实施方案

1. 恢复按 tab 级别计算缩进的旧逻辑。
2. 每个缩进层级仍然对应一个固定宽度的色块。
3. 保持代码块背景色为 `#1e1f20`。

## 验收标准

1. 代码块缩进只按 tab 级别渲染，不再按列切片。
2. 代码块缩进视觉恢复到较稳定、较简单的效果。
3. `npm run build` 可通过。
