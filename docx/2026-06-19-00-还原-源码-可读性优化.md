# FlowMD VSIX 源码还原与可读性优化 Spec

## 背景

当前目录是 FlowMD VS Code 扩展的 VSIX 解包结果，主要可用源码线索来自 `extension/dist/extension.js.map` 与 `extension/dist/webview.js.map`。

## 目标

1. 从 source map 的 `sourcesContent` 字段还原可阅读源码。
2. 将还原结果输出到项目根目录下的 `recovered` 目录。
3. 对还原源码进行格式化，提升阅读体验。
4. 生成源码索引与说明文档，帮助后续学习项目结构。

## 范围

包含：

- `extension/dist/extension.js.map` 中的项目源码。
- `extension/dist/webview.js.map` 中的项目源码。
- `extension/package.json`、`extension/README.md` 等学习入口文件的引用说明。

不包含：

- 修改原始 `extension/dist/*.js` 构建产物。
- 重建完整可发布扩展工程。
- 修改 VSIX manifest 或扩展运行逻辑。

## 实施方案

1. 读取两个 source map 文件。
2. 仅提取 `../src/` 下的项目源码，避免把第三方依赖源码混入学习目录。
3. 输出到 `recovered/src/...`。
4. 复制关键项目元信息到 `recovered/package.json`，便于编辑器识别项目依赖和脚本。
5. 使用 Prettier 对 `recovered/src` 下的源码进行格式化。
6. 创建 `recovered/README.md`，说明推荐阅读顺序。

## 验收标准

1. `recovered/src/extension`、`recovered/src/webview`、`recovered/src/shared` 至少一个存在。
2. 还原文件数量大于 0。
3. TypeScript、JavaScript、CSS 文件经过格式化处理。
4. `recovered/README.md` 提供清晰学习路径。
5. 原始 VSIX 解包文件不被破坏。
