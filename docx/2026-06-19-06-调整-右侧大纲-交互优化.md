# FlowMD 右侧大纲交互优化 Spec

## 背景

已有右侧大纲面板可以展示 Markdown 标题树，并支持拖拽宽度与标题跳转。本轮希望把它进一步打磨成更接近 VS Code 原生侧边栏的体验，重点修复滚动时的视觉偏移、收紧边距，并补充底部操作区与标题提示能力。

## 目标

1. 修复大纲在垂直滚动时出现的一次性视觉偏移。
2. 让大纲内容从面板顶部和左侧边缘开始，尽量贴边显示。
3. 在大纲面板底部增加固定操作栏，提供“展开全部”和“折叠全部”两个按钮。
4. 将展开/折叠图标替换为更接近 VS Code 内置风格的 glyph。
5. 为标题文本增加 1 秒悬停延迟提示，展示完整标题。
6. 保持层级配色严格按照 `level 1 -> color1, level 2 -> color2 ...` 循环，不允许按根分支重新分配。

## 范围

仅修改以下文件：

- `src/extension/webviewContent.ts`
- `src/webview/outlinePanel.ts`

不修改其他功能模块，不调整 Markdown 内容渲染逻辑，不改变标题跳转语义。

## 设计说明

### 1. 布局

- `outline-pane` 使用纵向 flex 布局。
- 大纲内容区占据可滚动主区域。
- 底部操作栏固定在面板底部，始终可见。
- 内容区不再保留多余的顶部和左侧内边距。

### 2. 交互

- 点击标题行仍然跳转到对应行。
- 点击展开/折叠按钮只切换当前节点状态。
- “展开全部”按钮展开整棵树。
- “折叠全部”按钮收起所有有子节点的标题。

### 3. 图标

- 展开/折叠图标使用更接近 VS Code 内置风格的单字符 glyph。
- 若环境不支持图标字体，则退回到简洁可读的符号文本。

### 4. Tooltip

- 悬停在标题行上时，不立即显示提示。
- 连续悬停满 1 秒后，显示完整标题。
- 离开标题行时，提示立即关闭。
- 提示内容必须是完整标题，不能截断。

### 5. 配色

- 标题层级颜色严格按层级对应：`level 1` 使用第 1 个颜色，`level 2` 使用第 2 个颜色，以此类推。
- 当层级超过颜色数时，再按顺序循环。
- 同一层级标题必须保持同一种层级配色。

## 验收标准

1. 右侧大纲滚动时不再出现一次性错位或跳闪。
2. 大纲内容区与面板顶部、左侧边缘对齐，没有额外缩进。
3. 底部操作栏始终固定在大纲面板底部。
4. “展开全部”和“折叠全部”按钮可正常工作，且不会影响跳转逻辑。
5. 标题图标风格统一，视觉上更接近 VS Code。
6. 标题悬停 1 秒后可看到完整文本提示，离开后立即消失。
7. 层级配色按标题 level 严格循环，渲染结果稳定一致。
