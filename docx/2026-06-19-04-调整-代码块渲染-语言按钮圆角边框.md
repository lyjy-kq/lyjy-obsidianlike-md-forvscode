# FlowMD 代码块渲染调整 Spec

## 背景

当前 FlowMD 的 fenced code block 在 live preview 中会应用背景、语法配色和复制按钮等渲染效果。用户希望将代码块改成更轻量的阅读样式，只保留必要交互，并复用现有的缩进可视化效果。

## 目标

1. 代码块在 live preview 中不再应用额外的渲染装饰。
2. 代码块仅保留一个复制按钮，按钮文字显示当前代码块语言。
3. 复制按钮点击后的复制行为保持不变。
4. 代码块外观仅保留圆润边框。
5. 代码块内部继续复用缩进高亮效果。

## 范围

包含以下文件的调整：

- `src/webview/codemirror/extensions/livePreview/plugin.ts`
- `src/webview/codemirror/extensions/livePreview/widgets.ts`
- `src/webview/codemirror/extensions/livePreview/styles.ts`
- `src/webview/codemirror/extensions/livePreview/helpers.ts`

不包含以下内容：

- Mermaid 渲染逻辑变更
- 表格、脚注、数学公式、图片等组件逻辑变更
- 导出 HTML 渲染逻辑变更
- 源码编辑器的 Markdown 解析逻辑变更

## 实施方案

1. 在 fenced code block 处理中提取语言标识，作为复制按钮的展示文案。
2. 保留复制按钮的点击复制功能，文案从固定 `Copy` 改为语言名。
3. 移除 code block 原有的背景填充式渲染，只保留圆角边框样式。
4. 为 code block 行添加缩进视觉效果，复用现有缩进色彩方案，呈现类似 indent-rainbow 的层级指示。
5. Mermaid 代码块维持原有图形渲染，不受此次调整影响。

## 验收标准

1. 普通 fenced code block 只显示语言按钮、圆角边框和缩进高亮效果。
2. 点击语言按钮后仍然可以正常复制代码内容。
3. 代码块不再显示原有背景块渲染效果。
4. Mermaid、表格、数学公式等现有组件表现不受影响。
5. `npm run build` 可正常通过。
