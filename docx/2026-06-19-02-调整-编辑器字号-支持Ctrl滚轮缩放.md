# FlowMD 编辑器字号支持 Ctrl 滚轮缩放 Spec

## 背景

FlowMD 目前支持 `Alt + 滚轮` 快速滚动，但不支持 VS Code 常见的 `Ctrl + 滚轮` 编辑器字号缩放行为。用户在 Markdown 主编辑区内滚动时，无法像 VS Code 代码编辑器那样临时放大或缩小文字。

## 目标

1. 在 Markdown 主编辑区内支持 `Ctrl + 滚轮` 调整代码文字大小。
2. 缩放只影响编辑区正文文本，不改变整个 webview 页面缩放。
3. 与现有 `Alt + 滚轮` 快速滚动行为共存，不相互干扰。
4. 保持现有编辑、预览、搜索、同步与快捷键逻辑不变。

## 范围

包含以下文件：

- `src/webview/codemirror/editor.ts`
- `src/extension/webviewContent.ts`
- `src/webview/codemirror/extensions/theme.ts`

不包含：

- VS Code 全局设置改动
- 消息协议改动
- 构建产物手工修改

## 实施方案

1. 为编辑区正文引入可缩放的字体大小 CSS 变量。
2. 在 CodeMirror 编辑器的滚轮事件中识别 `Ctrl + 滚轮`。
3. `Ctrl + 向上滚轮` 放大字体，`Ctrl + 向下滚轮` 缩小字体。
4. 通过编辑器容器上的 CSS 变量更新字号，避免影响页面其余区域。
5. 保留 `Alt + 滚轮` 的快速滚动行为优先级，避免误触时操作混乱。

## 验收标准

1. 在 Markdown 主编辑区按住 `Ctrl` 并滚动鼠标滚轮，可以看到正文文字变大或变小。
2. 只影响编辑器正文区域，不会把整个 webview 的按钮、外壳一起缩放。
3. `Alt + 滚轮` 仍然保持快速滚动。
4. `npm run build` 可以正常通过。
