# FlowMD 右侧大纲面板 Spec

## 背景

当前 FlowMD 的主界面只有 Markdown 编辑区，没有单独的大纲浏览区域。用户希望在界面右侧增加一块独立的大纲区域，用于按标题层级快速跳转，并且该区域支持拖动调整宽度，重启后仍然保留上次的宽度。

## 目标

1. 在 Markdown 主界面右侧增加大纲面板。
2. 大纲以树状层级展示标题，支持展开和收起。
3. 不同层级使用可区分的视觉样式，形成清晰的层级感。
4. 面板宽度可拖动调整。
5. 面板宽度在重启后仍然保持上次设置。
6. 不影响现有编辑、预览、搜索、图片、同步和主题切换逻辑。

## 范围

包含以下文件：

- `src/extension/editorProvider.ts`
- `src/extension/webviewContent.ts`
- `src/shared/messageTypes.ts`
- `src/shared/types.ts`
- `src/webview/main.ts`
- `src/webview/messageHandler.ts`
- `src/webview/codemirror/editor.ts`
- `src/webview/codemirror/extensions/theme.ts`
- 必要时新增少量辅助模块

不包含：

- 现有 Markdown 内容格式的迁移
- 文档渲染引擎替换
- 构建产物手工修改

## 设计说明

### 视觉结构

1. 大纲采用层级树形折叠结构。
2. 一级、二级、三级标题使用不同的底色或强调方式区分层级。
3. 展开和收起状态使用箭头或勾形状态符号区分。
4. 大纲区域整体风格与 VS Code 编辑器主题保持一致。

### 交互说明

1. 点击标题可跳转到正文对应位置。
2. 点击展开箭头可折叠或展开子标题。
3. 拖动中间分隔条可改变右侧大纲宽度。
4. 宽度变化后自动保存。
5. 再次打开或重启后，恢复上次宽度。

## 实施方案

1. 扩展侧在 webview 初始化时注入上次保存的大纲宽度。
2. Webview 侧新增右侧大纲容器、可拖拽分隔条和标题树渲染逻辑。
3. Webview 侧根据编辑器内容解析 Markdown 标题并构建大纲数据。
4. Webview 侧在内容变化时刷新大纲，并保持折叠状态尽量稳定。
5. 宽度通过扩展侧持久化存储，确保重启后恢复。

## 验收标准

1. 打开 `.md` 文件后，界面右侧显示大纲面板。
2. 大纲可以按标题层级展开和收起。
3. 拖动分隔条可以调整右侧大纲区域宽度。
4. 关闭再打开，或重启 VS Code 后，宽度仍然保持。
5. `npm run build` 可以正常通过。
