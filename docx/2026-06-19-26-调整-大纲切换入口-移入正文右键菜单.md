# 2026-06-19 26 调整 大纲切换入口 移入正文右键菜单

## 背景

此前已经把“大纲隐藏/打开”入口放到了编辑栏标题区，但用户明确希望该入口也不要出现在编辑栏，而是改回 Markdown 正文的右键菜单。

## 目标

1. 移除编辑栏标题区里的大纲切换按钮。
2. 将大纲切换入口加入 Markdown 正文右键菜单。
3. 该入口仅在 FlowMD 的 Markdown 正文区域生效。
4. 右键菜单打开时，按钮文案根据当前状态显示为“隐藏大纲”或“打开大纲”。

## 范围

### 需要修改

- `package.json`
- `src/webview/editorContextMenu.ts`
- `src/webview/main.ts`

### 不修改

- 大纲的解析、渲染和折叠逻辑
- 正文右键菜单中的导出 HTML 功能
- 其他编辑模式按钮逻辑

## 方案

1. 从 `package.json` 的 `editor/title` 中移除大纲按钮。
2. 在 `EditorContextMenuActions` 中新增“大纲切换”回调。
3. 在正文右键菜单里新增“大纲切换”按钮。
4. 菜单打开时根据当前大纲显隐状态刷新按钮文案。
5. 点击后直接在 webview 内切换大纲显隐，不经过编辑器标题栏。

## 验收标准

1. 编辑栏标题区不再显示大纲切换按钮。
2. Markdown 正文右键菜单里可以看到大纲切换入口。
3. 点击后大纲能在显示和隐藏之间切换。
4. 按钮文案会随当前状态切换。
