# FlowMD 主界面主题对齐 VS Code 编辑器 Spec

## 背景

FlowMD 当前的 Markdown 主界面虽然已经接入部分 VS Code 主题变量，但 CodeMirror 编辑区仍然保留了多处固定的浅色/深色背景与字体颜色配置，导致视觉上与 VS Code 的代码编辑主界面不完全一致。

## 目标

1. 让 Markdown 主编辑区的背景色跟随 VS Code 编辑器背景变量。
2. 让 Markdown 主编辑区的前景色跟随 VS Code 编辑器前景变量。
3. 让 Markdown 主编辑区的字体族、字号、行高尽量与 VS Code 编辑器保持一致。
4. 保持现有功能行为不变，不改动编辑、预览、搜索、快捷键与消息通信逻辑。

## 范围

包含以下文件的样式调整：

- `src/extension/webviewContent.ts`
- `src/webview/codemirror/extensions/theme.ts`

不包含：

- 业务逻辑改动
- 消息协议改动
- 构建产物手工修改

## 实施方案

1. 将 webview 外壳的 `body` 样式补齐为 VS Code 编辑器字体与字号变量。
2. 将 CodeMirror 根容器与 `.cm-content` 的背景色、前景色、字体族改为优先读取 VS Code 编辑器变量。
3. 保留原有的 fallback 值，避免在变量缺失时出现不可读样式。
4. 不修改 Markdown 内容结构和编辑器交互逻辑。

## 验收标准

1. 打开 `.md` 文件后，主编辑区域的背景颜色与当前 VS Code 编辑器背景一致。
2. 主编辑区域的文字颜色与当前 VS Code 编辑器前景色一致。
3. 主编辑区域的字体族和字号与 VS Code 编辑器一致或尽量一致。
4. `npm run build` 可以正常通过。
