# 2026-06-19 32 调整 图片渲染 Ctrl 点击打开本地文件
## 背景

当前 FlowMD 的图片已经可以在预览区正常显示，但图片本身的交互行为还不够顺手。
用户希望在正文里对图片进行 `Ctrl+Click` 时，能够像普通链接一样直接在 VS Code 中打开对应图片文件，便于快速查看原图或定位本地资源。

## 目标

1. 在预览区中，图片支持 `Ctrl+Click` / `Cmd+Click` 打开本地图片文件。
2. 仅对本地图片路径生效，远程图片与 data URI 不触发本地打开。
3. 保持现有图片渲染样式不变，不影响普通链接的点击行为。

## 范围

### 需要修改

- `src/webview/codemirror/extensions/livePreview/widgets.ts`

### 可能复用

- `src/extension/editorProvider.ts` 里已有的 `vscode.open` 打开逻辑
- `src/shared/messageTypes.ts` 里已有的 `openFile` 消息约定

### 不需要修改

- 图片下载逻辑
- 图片插入逻辑
- 其他 Markdown 语法渲染逻辑

## 实现方案

1. 在 `ImageWidget` 上增加点击交互。
2. 当用户按住 `Ctrl` 或 `Cmd` 点击图片时，向扩展侧发送 `openFile` 消息。
3. 扩展侧复用现有 `vscode.open` 打开本地文件的实现。
4. 对于远程图片和 `data:` 图片，点击不执行本地打开。
