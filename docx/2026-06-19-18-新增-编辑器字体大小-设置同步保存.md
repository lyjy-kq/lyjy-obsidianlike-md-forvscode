# 2026-06-19-18 新增编辑器字体大小设置并同步保存

## 目标
为 FlowMD 编辑器新增一个可在 VS Code 设置中配置的“字体大小”选项。
用户通过 `Ctrl + 滚轮` 调整正文缩放后，新的字号值需要同步写回设置，下次重新打开编辑器时仍保持上一次的字号。

## 需求
1. 在 `FlowMD` 设置中新增字体大小相关配置项。
2. 配置项应能在初始化时恢复到编辑器。
3. `Ctrl + 滚轮` 调整字号时，必须同步更新设置值。
4. 重新打开编辑器后，字号应与上次退出时保持一致。
5. 现有的行号、换行、可读行宽设置行为保持不变。

## 实现约定
1. 字体大小使用可持久化的数值配置，优先通过扩展配置系统保存。
2. Webview 内部缩放继续沿用当前 `Ctrl + 滚轮` 交互，但需要把变化通知扩展侧。
3. 扩展侧收到字号变化后，应更新 VS Code 配置并广播最新设置。
4. 配置项名称、默认值、上下限需与现有编辑器渲染逻辑兼容。

## 验收标准
1. 设置界面能看到新的字体大小选项。
2. 修改设置后，重新打开编辑器时字号正确恢复。
3. `Ctrl + 滚轮` 调整字号后，设置中的数值会同步变化。
4. 构建可正常通过，不影响现有编辑与大纲功能。
