# 调整正文右键菜单仅正文生效 Spec

## 背景

FlowMD 的 Markdown 编辑区是通过 Webview + CodeMirror 渲染的，不是 VS Code 原生文本编辑器。因此，`editor/context` 这类 VS Code 菜单贡献无法稳定作用到正文区域。为了让 `insert image` 和模式切换真正出现在 Markdown 正文的鼠标右键菜单中，需要在 Webview 内部单独实现一个正文专用右键菜单。

## 目标

1. 仅在 Markdown 正文区域的鼠标右键中显示菜单。
2. 菜单中保留 `insert image`。
3. 菜单中保留模式切换入口。
4. 不影响大纲面板、标题栏、拖拽分隔条和其它 Webview 交互。

## 范围

本次仅调整以下文件：

- `src/webview/main.ts`
- `src/webview/messageHandler.ts`
- `src/shared/messageTypes.ts`
- `src/shared/types.ts`
- `src/extension/editorProvider.ts`
- `package.json`

如需新增辅助文件，可新增一个仅负责正文右键菜单的 Webview 模块。

## 设计约束

1. 右键菜单必须绑定到正文区域，不应在大纲区域或空白 UI 区域弹出。
2. 菜单行为应与原功能一致，`insert image` 仍然打开图片选择器，模式切换仍然切换 Live / Viewer / Source。
3. 菜单样式应与 VS Code 深色/浅色主题尽量保持一致。
4. 不引入额外的编辑器内容改动，不影响正文编辑与同步逻辑。

## 验收标准

1. 在 Markdown 正文内右键，会出现 FlowMD 自定义菜单。
2. 在大纲面板、标题栏或其它非正文区域右键，不会弹出这个菜单。
3. 菜单里的 `insert image` 和模式切换都能正常执行。
4. 编辑器内容编辑、模式切换、图片插入和同步逻辑保持正常。
