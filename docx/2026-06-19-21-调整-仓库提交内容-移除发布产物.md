# 调整仓库提交内容移除发布产物 Spec

## 背景

当前仓库中包含用于本地说明的 `docs/` 目录，以及用于本地安装测试的 `flow-md.vsix` 文件。它们属于发布辅助内容，不适合继续作为仓库追踪文件被提交到远程。

## 目标

1. 将 `docs/` 目录从 Git 跟踪中移除，但保留本地文件。
2. 将 `flow-md.vsix` 从 Git 跟踪中移除，但保留本地文件。
3. 更新忽略规则，避免这类发布产物再次被误提交。
4. 不影响扩展源码、构建产物和运行逻辑。

## 范围

本次仅调整以下文件：

- `.gitignore`
- Git 索引中的 `docs/`
- Git 索引中的 `flow-md.vsix`

## 设计约束

1. 只移除仓库跟踪关系，不删除本地文件内容。
2. 发布说明文档和本地 `.vsix` 包都保留在工作区，方便开发和测试。
3. 忽略规则需要覆盖未来生成的 `.vsix` 文件。

## 验收标准

1. `git status` 不再显示 `docs/` 和 `flow-md.vsix` 为已跟踪变更。
2. 本地仍然可以看到 `docs/插件发布教程.md`。
3. 本地仍然可以看到 `flow-md.vsix`。
4. 后续重新打包生成的 `.vsix` 不会再被误加入提交。
