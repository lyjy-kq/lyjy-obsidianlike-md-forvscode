# 2026-06-19 25 调整 编辑栏按钮 隐藏导出HTML并新增大纲切换

## 背景

当前 FlowMD 的编辑栏标题区中存在 `Export as HTML` 入口，但同一功能已经在正文右键菜单中提供，容易造成入口重复。

同时，用户希望在编辑栏标题区新增一个只对 Markdown 文件显示的按钮，用于快速隐藏/打开右侧大纲。

## 目标

1. 隐藏编辑栏标题区里的 `Export as HTML` 按钮。
2. 在编辑栏标题区新增一个“大纲切换”按钮。
3. 该按钮仅在当前文档是 `.md` 文件时显示。
4. 点击后可在“显示大纲”和“隐藏大纲”之间切换。
5. 不影响正文右键菜单中现有的 `Export as HTML` 功能。

## 范围

### 需要修改

- `package.json`
- `src/extension/index.ts`
- `src/extension/editorProvider.ts`
- `src/webview/main.ts`
- `src/webview/outline.ts` 或 `src/webview/outlinePanel.ts`

### 不修改

- 正文右键菜单的导出 HTML 功能
- 其他编辑模式按钮逻辑
- 大纲内容解析与折叠逻辑

## 方案

### 1. 隐藏导出 HTML 按钮

在 `package.json` 的 `editor/title` 相关菜单中移除 `flowMd.exportAsHtml`。

如果标题栏右键菜单也属于重复入口，则一并移除，只保留正文右键菜单和资源管理器相关入口。

### 2. 新增大纲切换命令

新增命令，例如 `flowMd.toggleOutline`，由扩展侧转发到 webview。

该命令只在存在活动 FlowMD 编辑器时生效。

### 3. webview 侧切换大纲显隐

在 webview 中给 `OutlinePanel` 增加一个公开的切换方法，例如：

- `toggleVisibility()`
- 或 `setVisible(visible: boolean)`

切换时同时处理：

- 大纲面板本体
- 大纲拖拽分隔条
- 大纲占用宽度的恢复与隐藏

### 4. 编辑栏按钮显示条件

在 `package.json` 的 `editor/title` 菜单中新增 `flowMd.toggleOutline`，并加上 `.md` 文件条件。

按钮显示应满足：

- 当前文件后缀为 `.md`
- 当前激活的是 FlowMD 编辑器

## 验收标准

1. 编辑栏不再出现 `Export as HTML` 按钮。
2. 正文右键菜单仍可导出 HTML。
3. `.md` 文件标题栏出现大纲切换按钮。
4. 非 `.md` 文件不显示该按钮。
5. 点击按钮后，大纲能正常隐藏和恢复。
6. 隐藏后编辑区应正常占满空间，恢复后仍沿用原来的大纲宽度。

## 测试建议

1. 打开一个 `.md` 文件，确认标题栏按钮变化。
2. 点击大纲切换按钮，确认大纲可隐藏、可恢复。
3. 切换后刷新或重新打开文档，确认大纲状态和宽度行为正常。
4. 验证正文右键菜单里的导出 HTML 仍然可用。
