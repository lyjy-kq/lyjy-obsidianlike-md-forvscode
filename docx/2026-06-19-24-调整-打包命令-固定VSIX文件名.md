# 调整打包命令固定VSIX文件名 Spec

## 背景

当前 VSIX 打包命令虽然能生成安装包，但输出文件名默认会带版本号。为了让发布产物命名更统一，建议把打包命令固定为直接输出 `lyjy-obsidianlike-md.vsix`。

## 目标

1. 新增固定输出文件名的打包命令。
2. 让打包结果直接生成 `lyjy-obsidianlike-md.vsix`。
3. 同步更新文档中的打包示例命令。
4. 不改变扩展运行逻辑。

## 范围

本次仅调整以下文件：

- `package.json`
- `README.md`
- `docs/插件发布教程.md`

## 设计约束

1. 仍然使用 `vsce package`。
2. 保留现有构建前置流程。
3. 输出文件名固定为 `lyjy-obsidianlike-md.vsix`。

## 验收标准

1. 一条命令即可打包出 `lyjy-obsidianlike-md.vsix`。
2. README 中的打包示例与实际命令一致。
3. 发布教程中的示例命令与实际命令一致。
